# Nasaq Care — Android Builds

Android APK releases for [Nasaq Care](https://nasaqcare.com), a multi-tenant clinic management platform for clinics and medical centers.

## About the app

- Appointments and a live reception-to-doctor queue
- Patient records and e-prescriptions
- Invoices, payments, and receipts
- Multi-branch access with role-based permissions
- Arabic and English with full RTL support

## Install

1. Download the APK on your Android device.
2. Allow installation from your browser or file manager if prompted.
3. Open the app and sign in with your clinic account.
